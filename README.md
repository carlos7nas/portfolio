# Portfólio de Carlos Vitor do Nascimento (React)

## Para colocar no ar (GitHub Pages)
Envie para o repositório `carlos7nas.github.io` o conteúdo da pasta `dist/`
(o arquivo `index.html` e as pastas `assets` e `img`). Ela já está compilada.

## Para editar o site
- Textos, projetos, certificados e contatos: `src/data.js`
- Cores e layout: `src/styles.css`
- Seções: `src/sections/`
- Imagens: `public/img/`

Com o Node.js instalado:

    npm install
    npm run dev      # abre o site para editar
    npm run build    # gera a pasta dist/ atualizada
